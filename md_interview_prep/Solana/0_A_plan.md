# 🚀 4-Week Daily Solana Developer Learning Plan

---

## Week 1 — Foundations & Core Programming

| Day | Focus                          | Activity                                                            | Notes                                                                                |
| --- | ------------------------------ | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 1   | Solana Overview & Architecture | Read Solana Docs: Cluster Overview & Accounts Model                 | [https://docs.solana.com/cluster/overview](https://docs.solana.com/cluster/overview) |
| 2   | Anchor Basics                  | Build & run a basic Anchor program (Hello World)                    | Anchor CLI & Anchor Lang                                                             |
| 3   | PDAs & Seeds                   | Deep dive PDA derivation, seeds, bump; Write PDA code snippet       | Anchor constraints practice                                                          |
| 4   | Token Program                  | Explore SPL Token Program basics & minting tokens                   | Use Solana CLI & token-swap examples                                                 |
| 5   | CPI Calls                      | Write a small Anchor program that calls SPL Token Program           | Focus on CPI syntax & constraints                                                    |
| 6   | Anchor Accounts & Constraints  | Explore `#[account]` macro options, testing account deserialization | Review Anchor docs                                                                   |
| 7   | Write Tests                    | Write your first Anchor test in TypeScript                          | Use Mocha & Anchor test framework                                                    |

---

## Week 2 — Intermediate: Projects & Ecosystem

| Day | Focus                      | Activity                                                       | Notes                                     |
| --- | -------------------------- | -------------------------------------------------------------- | ----------------------------------------- |
| 8   | Fork & Study Repo          | Pick Metaplex token-metadata, read core structs & instructions | Summarize logic in notes                  |
| 9   | Implement Simple Extension | Add a small feature/fix in Metaplex repo locally               | Example: add an event or field            |
| 10  | NFT Minting                | Write an Anchor program minting NFTs using Metaplex            | Test locally & on devnet                  |
| 11  | Oracles & CPI              | Integrate a Pyth oracle call in your program                   | Read Pyth docs & examples                 |
| 12  | DAO Basics                 | Study SPL Governance repo and understand proposals             | Map state machine in diagrams             |
| 13  | Build DAO Vote             | Build a small DAO vote Anchor program                          | Write tests for proposal & vote           |
| 14  | Review Security            | Practice common exploits & Anchor constraints                  | Edge cases, PDA collisions, signer checks |

---

## Week 3 — Advanced Patterns & Performance

| Day | Focus                   | Activity                                         | Notes                             |
| --- | ----------------------- | ------------------------------------------------ | --------------------------------- |
| 15  | Escrow & Multisig       | Build escrow logic with multisig wallets         | Use Anchor and system programs    |
| 16  | Compute Unit Profiling  | Measure compute units in your Anchor program     | Use `msg!()` & `solana logs`      |
| 17  | Parallel Tx Execution   | Study how Solana handles tx parallelism          | Write notes on account locking    |
| 18  | Upgradable Programs     | Practice program upgrades with Anchor            | Deploy upgrade & rollback locally |
| 19  | Complex CPIs            | Compose multiple CPI calls with error handling   | Example: staking + reward claim   |
| 20  | Write Integration Tests | Simulate full user flow (stake, vote, claim)     | Validate edge case failures       |
| 21  | Ecosystem Tools         | Explore Solana Explorer, SolanaFM, and dev tools | Bookmark & practice usage         |

---

| Day | Focus                 | Activity                                        | Notes                                |
| --- | --------------------- | ----------------------------------------------- | ------------------------------------ |
